# Parâmetros de URL

Ao abrir este exercício no VS Code, você receberá um projeto Django já criado. O sistema a ser implementado é um "hello world" parametrizado. A ideia é que o seguintes textos sejam mostrados ao acessar as urls abaixo:

- ao acessar `http://localhost:8000/hello/Ana` deve ser mostrado o texto `Olá Ana!`
- ao acessar `http://localhost:8000/hello/Bernardo` deve ser mostrado o texto `Olá Bernardo!`
- ao acessar `http://localhost:8000/hello/Carla` deve ser mostrado o texto `Olá Carla!`

Uma parte do código já está implementada. Você **não deve** modificar o arquivo `app_principal/views.py`. Modifique apenas o arquivo `app_principal/urls.py` para fazer o projeto funcionar. Dica: apesar de não poder modificar, é importante que você leia e entenda o arquivo `app_principal/views.py`.
