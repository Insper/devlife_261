# Mapeando rotas

Ao abrir este exercício no VS Code, você receberá um projeto Django já criado. O sistema a ser implementado é um grande "hello world". A ideia é que o seguintes textos sejam mostrados ao acessar as urls abaixo:

- ao acessar `http://localhost:8000/comida` deve ser mostrado o texto `baião de dois`
- ao acessar `http://localhost:8000/filme` deve ser mostrado o texto `Estrelas Além do Tempo`
- ao acessar `http://localhost:8000/livro` deve ser mostrado o texto `O Design do Dia a Dia`

Uma parte do código já está implementada. Você **não deve** modificar nenhuma função já existente no arquivo `app_principal/views.py`, mas pode adicionar novas funções. Além disso, você também deve modificar um outro arquivo (cabe a você descobrir qual é).
