Depois de concluir nosso primeiro jogo, vamos continuar desenvolvendo nossas habilidades através de um tipo de aplicação muito comum: os sistemas web. Nesta etapa do curso, veremos algumas ferramentas e conceitos que são amplamente utilizados no desenvolvimento de soluções web, entre eles:

1. **Framework Django**: aprenderemos o básico de como utilizar este framework no desenvolvimento de aplicações web.
2. **Rotas, views, templates e formulários**: são todos termos utilizados no desenvolvimento Web.
3. **Persistência de dados**: este é um conceito que não está apenas relacionado a aplicações web. Basicamente, trata de como garantir que um dado foi salvo e que poderá ser recuperado no futuro quando necessário.
4. **CRUD**: é um acrônimo para *Create, Read, Update, Delete*. Em Ciência da Computação este acrônimo é utilizado para descrever as 4 operações básicas relacionadas com *persistência de dados* e muitas vezes também é utilizado para descrever *interfaces de usuários* utilizadas para visualizar, procurar e alterar dados.   

Em Developer Life, utilizaremos o framework [Django](https://www.djangoproject.com/). Antes de começar o desenvolvimento, precisamos introduzir alguns [conceitos básicos](introducao/index.md).
